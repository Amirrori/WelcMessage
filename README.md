# Introduction:
Semi-Modular Welcomer plugin for Paper servers.

## Requirements

- Server with at least Paper 1.20.1
- Java 17

# Setup


## JAR file
Drag and drop the jar file into your paper server's plugins directory.
Restart the server.


## Build from source

Clone the git repository.

Build using Maven:

Requirement: `maven`
```
cd /path/to/WelcMessage
mvn package
```
